# OmniForge Private Workbench

Private IPA analysis repository. Upload only applications you own or are authorized to analyze.

Workflow: `ipa-workbench.yml`. The OmniForge iPhone app uploads a selected IPA to a draft release and dispatches the workflow with `release_tag` and `ipa_asset`. Outputs include static reports and an independently compiled clean-room project; they do not guarantee reproduction of the original executable.
